# ADR 0012 — Swift 6.3 baseline and toolchain posture

**Status:** Accepted · 2026-09-01

## Context

The minimum toolchain is Swift 6.3 (released 2026-03-24). That is a free hand to use the
modern language without `#if` fallbacks, and this is a small, pure, security-sensitive
library — exactly the kind of code that benefits from the strictest settings the compiler
offers.

## Decision

`Package.swift` is `swift-tools-version: 6.3`. Both targets carry:

- **`.swiftLanguageMode(.v6)`** — full compile-time data-race checking.
- **`.defaultIsolation(nil)`** — every declaration is `nonisolated` by default. Soniqle
  touches no global actor; `compile` is a pure function. Stating this in the manifest means
  a project that flips its own default to `@MainActor` does not silently pull this library
  onto the main actor.
- **`.strictMemorySafety()`** — the implementation uses no `unsafe` constructs; the setting
  makes any future accidental introduction a compile error rather than a review miss.
- **Upcoming-feature flags** already satisfied: `ExistentialAny`, `InternalImportsByDefault`
  (every `import` is `internal` unless a type crosses the API boundary — only
  `SQLValue`'s `Date` needs `public import`), `MemberImportVisibility`,
  `NonisolatedNonsendingByDefault`.

Other choices that follow from the baseline:

- **Typed throws** everywhere: `throws(SoniqleError)`. See ADR 0013 for why that is safe on
  public API.
- **Swift Testing** (`import Testing`, `@Test`, `#expect`), which ships with the toolchain —
  no test-only package dependency.
- **`FoundationEssentials`** when available, `Foundation` otherwise, for `Date` and
  `JSONDecoder` only. No other dependencies.
- Warnings-as-errors is a CI flag (`swift build -Xswiftc -warnings-as-errors`), not
  `.unsafeFlags` in the manifest, which would make the package unusable as a dependency.

## Consequences

- No compatibility shims, no `@available` clutter.
- Consumers must be on Swift 6.3+. For a new library in 2026 this is a reasonable floor.
- The strict settings occasionally cost a few lines (explicit `public import`, no ambient
  `unsafe`); that is the intended trade.
